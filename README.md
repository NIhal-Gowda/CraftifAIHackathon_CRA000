# PipGen - Workplace Safety Sentinel (Dual-Solution Platform)

## 📌 Project Overview
This project maps directly to **Track 1: Workplace Safety Sentinel** under the PipGen challenge constraints. It operates as an automated computer vision pipeline compiler that translates natural language industrial prompts into structured system architectures. It dynamically tracks worker coordinates, verifies compliance with personal protective equipment (PPE/Helmets), and broadcasts low-latency emergency telemetry packages.

## 🛠️ Dual-Solution System (Cross-Linked Reference)
To ensure system redundancy and high availability across varying deployment restrictions, this application provides two distinct operational execution layers:
1. **Cloud Sandbox Simulation (Google Colab Python Core):** A clean, zero-configuration runtime implementation executing the telemetry compiler engine and data dictionary layers natively.
   * *Access Note for Judges:* The primary algorithmic parsing logic and JSON serialization structures are securely managed inside this file.
2. **Web Browser Simulation (HTML5/Tailwind/Vanilla JS Architecture):** A real-time visual matrix feed rendering mock camera streams, bounding boxes, and pipeline node tracking graphs instantly without software runtime bottlenecks.
